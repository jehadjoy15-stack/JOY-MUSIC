# Translation attribution

The shared translations in `shared/src/commonMain/composeResources/values-*` include strings originally imported from the
[official JoyMusic Android app](https://github.com/jehadjoy15-stack/JOY-MUSIC) at revision
[`6ee482cbe3a076092436a3cb1b53571ffead3097`](https://github.com/jehadjoy15-stack/JOY-MUSIC/tree/6ee482cbe3a076092436a3cb1b53571ffead3097/app/src/main/res).
JoyMusic distributes them under its GPL-3.0 license.

The JoyMusic and InnerTune localization communities contributed these translations.
Per-language and per-string contributor records are in the
[JoyMusic Weblate project](https://hosted.weblate.org/projects/joymusic/) and the
[official resource history](https://github.com/jehadjoy15-stack/JOY-MUSIC/commits/6ee482cbe3a076092436a3cb1b53571ffead3097/app/src/main/res).

The official JoyMusic translation-file history at the time of import credits
Alessio Attilio, Ameen, davbrasan, Dimitrys_AF, Draken, 𝗛𝗼𝗹𝗶, kevin0712, Lucas,
LucasMZ, MetalDroid, Michael Moroni, Mo Agamy, Mohamad Obeid, Mohammad Obeid,
Mostafa Al Agamy, Ramazan Sancar, xamax-code, and zhabafrog. Name variants in Git history
are combined in this list. The linked history preserves the original authorship.

Each imported resource file carries a source revision and a link back to this notice.
Do not remove those headers or this attribution when updating or redistributing the
translations.

KMP-specific translations are project contributions, not part of the upstream import. All translations live in
`shared/src/commonMain/composeResources/values-*/strings.xml` and are maintained through the
[JoyMusic KMP Weblate project](https://translate.joymusic.cc/projects/joymusic-kmp/joymusic-kmp/).
See [strings.md](strings.md) for the catalog workflow.
